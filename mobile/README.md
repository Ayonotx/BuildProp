# BuildProp Mobile — React Native (Expo)

Mobile companion app for BuildProp ERP.

## Setup

```bash
cd mobile
npm install
npx expo start
```

## Build APK

```bash
npx expo build:android
```

## Features
- Login with any BuildProp account
- Dashboard with KPIs
- Project list with status badges
- Task list with priority filters
- Contact search
- Server URL configuration
- Token persistence

## Connecting to Server
1. Launch the app
2. Enter your server URL (e.g., http://192.168.1.100:3456)
3. Login with your email and password
