## Workflow
1. Generate each scene clip (3-5 seconds each) using the prompts below
2. Download all clips
3. Open **CapCut** (free) → Import all clips
4. Trim each to 5-7 seconds
5. Add text overlays (scene titles) using CapCut's text tool
6. Add transitions (cross-fade between scenes)
7. Add background music (search "corporate tech" in CapCut's audio library)
8. Add voiceover (record yourself or use ElevenLabs free tier)
9. Export as 1080p MP4

## Pro Tips

1. **Generate 2-3 versions** of each scene and pick the best one
2. **Use the same style keywords** across all prompts for consistency: "corporate tech aesthetic, 4K, photorealistic, smooth camera movement"
3. **Add text in post-production** (CapCut) — AI video tools can't render text reliably
4. **Keep clips short** — 3-5 seconds per AI generation, then stretch to 5-7 in editing
5. **Music matters** — a good corporate track makes amateur footage look professional
6. **Export at 1080p minimum** — 4K is overkill for social media ads
